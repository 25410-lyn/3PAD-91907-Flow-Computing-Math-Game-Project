---------------Hello! Welcome to Kalc!-----------------------------


Please follow the following steps to ensure that you can run calc without any problems.

Install the following libraries:
-tkinter

Now, to navigate the program:

1. Launch the "Kalc Main Version (Final).py" file.
 	-Make sure you see music.mp3 in the folder before you launch it!
	-If you cannot find music.mp3, go into the backup folder to retrieve it.

2. You will see a login interface on the screen. Here, press create account.

3. Once the account creation window pops up, enter a username and password.
	-Sidenote: Username must be a minimum of 4 letter, while a password must be 8 min.

4. Press Create and hit ok when the "Account Created" message appears.

5. Login with the username and password.

6. Now you have reached the main menu, from this point, you can start playing and adjust the settings.

---------------------Enjoy!------------------------------------------
